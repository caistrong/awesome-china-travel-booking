# Contributing

Thanks for helping other travellers. This list is only useful if it is accurate, so a few ground rules:

1. **Official sources first.** Link the attraction's own site, notice or ticket page when you change a release time, price or rule.
2. **First-hand reports are welcome.** Please include the date, the attraction, your passport type (for example "US passport") and which channel you used. These go in as reports, not as official rules.
3. **No resellers or referral links.** Pull requests that add affiliate, referral or ticket-reseller links will be closed.
4. **Keep it short.** One or two lines per item, plus a link to a longer guide if needed.
5. **Dates matter.** If a rule has a start or end date (an exhibition, a seasonal opening, a policy change), write it down.

To suggest a change, open an issue or a pull request. If you are not sure about a fact, open an issue and say so; that is useful too.
